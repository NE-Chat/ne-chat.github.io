# 세계의 서고

나무 책상 위의 흑백 마도서를 펼쳐 들어가는 개인 세계관 도감입니다.

- 표지의 검정·흰색 반반 디자인을 유지하며 정면에 크게 배치합니다.
- 책 또는 펼치기 버튼을 누르면 표지가 열리고 종이의 굴곡과 층이 보이는 책장이 나타납니다.
- 흑백 연기는 입장 전까지 계속 피어오릅니다. 입장 버튼으로 도감에 들어갑니다.
- 건너뛰기, 책 다시 펼치기, 세계관·캐릭터·장소 분류 전환을 지원합니다.
- 도감의 실제 내용은 아직 비어 있습니다.
- 별도 서버, 외부 라이브러리, 외부 폰트나 추적 코드가 없습니다.

## 파일과 게시

GitHub Pages에서 main 브랜치의 루트를 게시합니다.

- `index.html`: 화면과 도감 구조
- `style.css`: 반응형 배치, 표지 열기와 종이의 미세한 움직임
- `app.js`: 지속적인 연기 입자 애니메이션과 화면 전환
- `cover.webp`: 흑백 가죽과 은장식 표지
- `open-book.webp`: 종이의 곡면과 쌓인 책장, 은장식이 있는 펼친 책
- `smoke.webp`: 투명 배경의 세밀한 연기 입자 질감
- `wood.webp`: 화면 전체를 채우는 나무 책상
- `emblem.svg`: 도감 문양

책과 배경을 별도로 배치하여 화면 비율이 달라도 책 전체가 보이도록 합니다. 배경은 cover로 빈틈 없이 채우므로 나뭇결 가장자리의 보이는 범위는 화면마다 다릅니다. Canvas는 실제 표시 크기와 기기 픽셀 밀도(최대 2배)에 맞춰 렌더링합니다. 고정 QHD 이미지를 늘려 화면 전체를 만드는 방식은 아닙니다. 모션 줄이기 설정에서는 정적인 연기를 표시하며, 비활성 탭과 도감 내부에서는 입장 화면의 렌더링을 중단합니다.

## 확인

JavaScript 구문, 책 펼침, 도감 입장, 분류 전환, 다시 펼치기를 확인했습니다. 320×568, 390×844, 844×390, 2560×1440, 3440×1440, 3840×2160 브라우저 뷰포트에서 책 배치와 가로·세로 넘침을 확인했습니다. 모바일 실기기 성능 검증을 대신하지 않습니다.

## 이미지 제작 기록

이미지는 내장 이미지 생성 도구로 제작한 자산을 WebP로 인코딩했습니다. 원본 크기는 표지 1024×1536, 나무 배경 1672×941, 펼친 책 1586×992, 연기 1280×1280입니다. 화면 출력 해상도와 원본 이미지 해상도는 다르며, 원본을 네이티브 QHD 또는 4K라고 표시하지 않습니다.

펼친 책 제작 프롬프트: 기존 흑백 가죽·은장식 표지를 참고한 정면의 대칭적인 펼친 마도서. 섬유 질감의 흰 종이, 중앙 제본으로 부드럽게 휘는 페이지, 아래쪽에 수백 장의 얇은 종이 층. 희미한 천체 문양과 필기. 자연스럽고 낮은 책등, 과장된 받침대 없이 얇은 표지 테두리. 투명 배경, 책상·연기·발광·큰 문구 없음. 2560×1600 이상을 요청했으며 실제 반환 크기는 위에 기재.

연기 제작 프롬프트: 투명 배경의 단일 흰색 연기 VFX 입자. 자연스럽게 말려 올라가는 미세한 소용돌이, 풍부한 내부 결, 부드러운 가장자리와 반투명한 섬유 같은 흐름. 검정 배경·불꽃·물체·글자·반짝임 없음. 중첩 애니메이션에 쓰는 정사각형 질감.
