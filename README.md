# NE · 도감

어두운 회색 나무 책상 위의 흑백 마도서를 펼치면 자동으로 확대되어 책 내부의 도감으로 이어지는 GitHub Pages 사이트입니다.

## 화면과 동작

- 책 원본 비율(1585:992)을 유지한 채 뷰포트 안에 맞춥니다. 가로/세로를 따로 늘리지 않으며 화면 회전과 브라우저 높이 변화 때 다시 계산합니다. 모바일 가로에서는 양쪽 면이 중앙에 함께 표시되고, 세로로 돌아오면 이전에 선택한 확대 면이 복원됩니다.
- 첫 표지 열림에서 별도의 사각형 종이층, 광택 사각형, 뒷면을 제거했습니다. 그림이 있는 표지만 90도까지 회전합니다.
- 상단 책갈피는 글자 수와 관계없이 동일한 폭입니다. 검은 가죽과 은빛 테두리로 제본 상단에 붙어 있으며 좁은 화면에서는 가로로 쓸어 선택합니다.

- 입장 확대는 연기 캔버스를 움직이지 않고, 책 이미지 한 장의 위치와 크기를 실제 도감 책 위치로 맞춥니다.

- 확대 후에는 실제 곡면·제본·종이층이 있는 빈 고서 이미지를 바탕으로 내용을 표시합니다.
- 페이지는 바탕 책의 상단 종이 표면을 같은 좌표에서 샘플링한 얇은 한 장을 약 1.1초 동안 연속 곡면으로 넘깁니다. 넘기는 면에는 제본이나 쌓인 종이층 이미지가 없습니다. 바탕 책은 고정됩니다. 동작 줄이기 설정에서는 즉시 이동합니다.

- 펼친 종이의 형태와 맞지 않는 직사각형 뒷면 및 흰 반사 레이어를 제거했습니다.
- 책을 클릭하면 열기 → 지속적인 흑백 연기 → 확대 → 약 5.9초 뒤 도감 입장 순서로 진행합니다.
- 첫 펼침면은 문양 없이 NE와 도감 제목으로 구성했습니다.
- 상단에는 전체·일상·판타지·아포칼립스·센티넬·시뮬레이션·콜라보·기타 책갈피가 있습니다.
- 전체 책갈피를 누르면 모든 캐릭터가 등록 순서대로 나옵니다. NE를 누르면 제목 면으로 돌아갑니다.
- 개별 카테고리 첫 페이지는 세계관·굵은 문양·카테고리 이름입니다. 일상은 달빛 찻잔과 식물, 판타지는 하트·날개·곡선으로 구성한 자궁문신 형태의 문장, 아포칼립스는 갈라진 일식과 가시, 센티넬은 날개와 수호의 눈, 시뮬레이션은 초승달·연꽃·꿈의 거울, 콜라보는 서로 얽힌 문양, 기타는 별과 열쇠구멍 문양을 사용합니다. 각 문양은 벡터로 그려져 해상도에 관계없이 선명합니다. 캐릭터는 2페이지부터 시작합니다.
- 책의 한쪽 면을 한 페이지로 계산합니다. 페이지당 최대 12명이며, 모든 화면에서 양쪽 페이지가 있는 펼침면을 유지합니다. 모바일 기본 보기는 책 전체이며, 왼쪽·전체·오른쪽 버튼으로 확대할 면을 선택합니다. 확대 상태에서는 화살표나 좌우 쓸기로 왼쪽 → 오른쪽 → 다음 펼침면 순서로 읽을 수 있습니다.
- 그리드의 크기와 간격은 화면 크기로만 정해집니다. 한 페이지에 1명이 있어도 12명일 때와 크기가 같습니다. 모바일에서는 화면 비율에 맞춰 3열×4행 또는 4열×3행을 선택합니다.
- 이미지 틀은 가로:세로 2:3입니다. object-fit: cover로 비율을 보존하며 넘치는 부분을 자릅니다.
- 카드 선택 시 캐릭터 이미지·이름·설정을 책의 종이와 어울리는 상세 화면에서 봅니다.
- 실제 캐릭터 자료는 아직 등록되지 않았으며, 검증용 데이터는 공개 사이트에 포함하지 않습니다.

## 캐릭터 등록

`characters.js`의 `catalog.characters` 배열에 아래 형식으로 추가합니다. 배열의 순서가 도감 순서이며, 페이지 생성과 카테고리 분류는 자동입니다.

```js
{
  id: 'character-001',
  name: '캐릭터 이름',
  categories: ['fantasy'],
  image: 'images/character-001.webp',
  position: '50% 50%',
  description: '캐릭터 설정',
  url: 'https://example.com/'
}
```

`image`는 프로젝트 이미지 경로나 HTTPS URL입니다. `position`으로 잘라 보일 중심을 조절할 수 있습니다. `description`, `url`은 생략할 수 있습니다. 이 파일에 기록한 내용은 공개됩니다. 카테고리 키는 daily, fantasy, apocalypse, sentinel, simulation, collab, other이며 복수 지정이 가능합니다. `catalog.worlds`에 카테고리별 세계관 설명을 추가할 수 있습니다.

## 검증

페이지당 12명 경계, 13번째 캐릭터의 다음 페이지 이동, 전체 목록의 순서와 중복 방지, 카테고리 필터, 빈 카테고리, 제목 면과 세계관 면의 페이지 이동을 검사했습니다. 브라우저에서 자동 입장, 여러 화면 크기의 책 배치, 최대 12개 카드의 비율·영역 넘침을 확인합니다. 대상 뷰포트: 320×568, 390×844, 844×390, 2560×1440, 3440×1440, 3840×2160. 실제 기기 성능 검증을 대신하지 않습니다.

## 이미지 자산

표지·펼친 책·연기·나무 배경은 이전 제작 자산을 사용합니다. 나무는 CSS에서 회색으로 조정했습니다. 종이 질감은 내장 이미지 생성 도구로 새로 제작하고 WebP로 인코딩했습니다. 최종 요청 프롬프트: 평평하게 내려다본 깨끗한 옅은 아이보리색 면지, 균일한 조명과 절제된 섬유 질감, 화면 끝까지 종이만 채움. 테두리·접힘·주름·그림자·얼룩·문자·문양 없음. 원본 이미지 크기와 브라우저 출력 해상도는 다릅니다.
