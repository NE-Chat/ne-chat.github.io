# 세계의 서고

나무 책상 위의 마법서를 펼쳐 입장하는 개인 세계관 도감입니다.

- 책을 클릭하거나 터치하면 표지와 페이지가 열리고 흑백 마법이 솟아오릅니다.
- 약 7초 후 도감으로 진입합니다. 건너뛰기와 다시 재생을 지원합니다.
- 세계관, 캐릭터, 장소는 내용을 추가하기 전의 빈 목차입니다.
- 외부 라이브러리, 외부 폰트, 분석 추적, 로그인, 별도 서버가 없습니다.
- 기기의 모션 줄이기 설정을 따릅니다.

## 게시
GitHub Pages: main 브랜치의 /(root)에서 게시합니다.

## 파일
- `index.html`: 입장 화면과 도감의 구조
- `style.css`: 화면 비율별 배치, 책의 3D 변형과 페이지 애니메이션
- `app.js`: 마법 리본·파편 Canvas 렌더링 및 화면 전환
- `cover.webp`, `wood.webp`, `page.svg`, `emblem.svg`: 책 표지, 나무 배경 및 벡터 문양

화면 전체를 하나의 고정 해상도 이미지로 사용하는 방식이 아닙니다. CSS로 화면에 맞춰 배치하고 Canvas는 실제 뷰포트와 픽셀 밀도(최대 2배)에 맞춰 렌더링합니다. 배경은 cover로 화면을 채우며 책은 별도로 비율을 유지합니다. 배경 가장자리의 무늬는 화면 비율에 따라 달라질 수 있습니다.

## 검증
JavaScript 구문 검사, 브라우저에서 책 열기·도감 진입·분류 전환·재생 확인. 390×844, 320×568, 844×390, 2560×1440, 3440×1440, 3840×2160 뷰포트 프레임에서 화면 크기와 책의 배치 확인. 모바일 실기기 검증을 대신하지는 않습니다.

## 이미지 제작
이미지는 내장 이미지 생성 기능으로 제작한 프로젝트 전용 자산입니다. 생성 요청의 목표 크기와 실제 생성 크기를 구분합니다. 배경의 실제 원본은 1672×941, 표지는 1024×1536이며 WebP로 인코딩했습니다. UI, 페이지 문양과 마법 효과는 벡터/실시간 렌더링입니다. 원본이 네이티브 4K인 것으로 표시하지 않습니다.

최종 표지 수정: 검정 가죽과 흰 가죽을 반반 배치하고 금장을 은장으로, 청록 보석을 흑백 수정으로 변경. 배경은 유지.

초기 표지 제작 프롬프트 요약: 참고 이미지의 짙은 남색 가죽, 두꺼운 조각 금장, 청록색 보석과 뾰족한 고딕 장식을 살린 정면 직교 투영 표지. 글자 없이, CSS 3D 책 표면에 적용하기 위한 직사각형 자산.

배경 제작 프롬프트 요약: 완전히 빈 앤티크 호두나무 책상을 수직으로 내려다본 표면, 자연스러운 수평 나뭇결과 은은한 이음매, 따뜻하고 차분한 조명. 요청은 3840×2160, 실제 반환 크기는 위에 기록한 크기.
