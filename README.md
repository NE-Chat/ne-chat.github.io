# NE · 도감

어두운 회색 나무 책상 위의 흑백 마도서를 펼치면 자동으로 확대되어 책 내부의 도감으로 이어지는 GitHub Pages 사이트입니다.

## 화면과 동작

- 입장: 닫힌 책 전체가 책상으로 내려앉은 뒤 같은 등 경첩에서 펼쳐집니다. 표지의 뒷면이 왼쪽 안쪽 면이므로 별개의 표지 그림이 남지 않습니다. 흑백 연기 뒤 실제 읽기 위치로 확대되며 약 6.1초 뒤 입장합니다.
- 모바일 세로: 처음부터 왼쪽 한 페이지를 화면 높이에 맞춰 크게 보여줍니다. 옆으로 쓸면 왼쪽 → 오른쪽 → 다음 펼침면 왼쪽 → 오른쪽 순서입니다. 같은 펼침면에서는 카메라만 이동하고, 다음 펼침면으로 갈 때는 얇은 종이 한 장과 카메라가 함께 움직입니다. 반대 방향 쓸기도 가능합니다.
- PC와 모바일 가로: 양쪽 페이지가 함께 보입니다. 쓸거나 마우스로 끌면 종이만 한 장 넘어가며 카메라는 좌우로 움직이지 않습니다. PC에서는 빈 페이지를 클릭하거나 키보드 좌우 키로도 넘길 수 있습니다.
- 화살표, 전체/왼쪽/오른쪽 보기 선택 버튼은 없습니다. 화면 회전 중 애니메이션은 정리하고 읽던 펼침면을 유지합니다. 모바일을 다시 세로로 돌리면 선택했던 쪽으로 돌아옵니다.
- 원본 책 비율은 유지합니다. 세로 모바일은 종이 면을 가까이 보므로 바깥 제본 장식 일부가 화면 밖에 있으며, 글과 캐릭터는 별도의 안전 영역 안에 맞춥니다.
- 카테고리는 같은 폭의 천 책갈피 8개입니다. 전체·일상·판타지·아포칼립스·센티넬·시뮬레이션·콜라보·기타 순이며, 두 페이지 보기에서는 가운데 제본 위를 비워둡니다.
- 첫 펼침면은 문양 없이 NE와 도감 제목입니다. 전체 책갈피는 등록된 모든 캐릭터를 순서대로 보여줍니다. NE는 첫 페이지로 돌아갑니다.
- 카테고리 첫 왼쪽 페이지는 세계관·카테고리별 문양·이름입니다. 캐릭터는 오른쪽 2페이지부터 시작합니다.
- 물리적인 한 페이지에 최대 12명입니다. 캐릭터가 1명이어도 칸이 늘어나지 않습니다. 세로 이미지 틀은 가로:세로 2:3이며 object-fit:cover로 초과 영역만 자릅니다.
- 넘기는 종이는 바탕 책의 상단 표면을 같은 좌표로 샘플링하고 제본과 종이 뭉치를 제외한 윤곽으로 자릅니다. 동작 줄이기 설정에서는 즉시 이동합니다.
- 실제 캐릭터는 아직 등록되지 않았으며, 검증용 캐릭터는 배포하지 않습니다.

## 캐릭터 등록

`characters.js`의 `catalog.characters` 배열에 아래 형식으로 추가합니다. 배열의 순서가 도감 순서이며, 페이지 생성과 카테고리 분류는 자동입니다.

```js
{
  id: 'character-001',
  name: '캐릭터 이름',
  categories: ['fantasy'],
  image: 'images/character-001.webp',
  position: '50% 50%',
  description: '캐릭터 설정',
  url: 'https://example.com/'
}
```

`image`는 프로젝트 이미지 경로나 HTTPS URL입니다. `position`으로 잘라 보일 중심을 조절할 수 있습니다. `description`, `url`은 생략할 수 있습니다. 이 파일에 기록한 내용은 공개됩니다. 카테고리 키는 daily, fantasy, apocalypse, sentinel, simulation, collab, other이며 복수 지정이 가능합니다. `catalog.worlds`에 카테고리별 세계관 설명을 추가할 수 있습니다.

## 게시 파일

main 브랜치의 루트를 GitHub Pages로 게시합니다. 별도 서버·로그인·외부 라이브러리가 없습니다.

필수 파일: index.html, style.css, app.js, catalog-core.mjs, book-layout.mjs, page-turn.mjs, characters.js, emblem-*.svg 7종, emblem.svg, cover.webp, open-book.webp, reader-book.webp, smoke.webp, wood.webp, paper.webp, .nojekyll.

## 검증

페이지당 12명 경계, 13번째 캐릭터의 다음 페이지 이동, 전체 목록의 순서와 중복 방지, 카테고리 필터, 빈 카테고리, 제목 면과 세계관 면의 페이지 이동을 검사했습니다. 브라우저에서 자동 입장, 여러 화면 크기의 책 배치, 최대 12개 카드의 비율·영역 넘침을 확인합니다. 대상 뷰포트: 320×568, 390×844, 844×390, 2560×1440, 3440×1440, 3840×2160. 실제 기기 성능 검증을 대신하지 않습니다.

## 이미지 자산

표지·펼친 책·연기·나무 배경은 이전 제작 자산을 사용합니다. 나무는 CSS에서 회색으로 조정했습니다. 종이 질감은 내장 이미지 생성 도구로 새로 제작하고 WebP로 인코딩했습니다. 최종 요청 프롬프트: 평평하게 내려다본 깨끗한 옅은 아이보리색 면지, 균일한 조명과 절제된 섬유 질감, 화면 끝까지 종이만 채움. 테두리·접힘·주름·그림자·얼룩·문자·문양 없음. 원본 이미지 크기와 브라우저 출력 해상도는 다릅니다.
